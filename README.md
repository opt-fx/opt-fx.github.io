# opt-fx.com

The front page for OPT's browser apps, served at [opt-fx.com](https://opt-fx.com).

Each app lives in its own repo under [opt-fx](https://github.com/opt-fx) and appears at `opt-fx.com/<repo>/`:

- [S950rx](https://opt-fx.com/s950rx/): Akai S950 and S900
- [S612 transfer](https://opt-fx.com/s612-transfer/): Akai S612
- [Seer](https://opt-fx.com/seer/): Sequential Prophet-5 and Prophet-10 Rev 4 (formerly Rev 4 Patch Engine)
- [Pad Loader](https://opt-fx.com/pad-loader/): MKSREC 1
- [QuChord](https://opt-fx.com/quchord/): any MIDI keyboard

Screenshots for each app's viewer are in `shots/` (`<app>-1.png`, `<app>-2.png`, taken at twice screen resolution). To replace one, overwrite the file with the same name; captions are in the `shots` list for each app in `index.html`.
